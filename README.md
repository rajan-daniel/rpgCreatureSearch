## 👾 Monster Vault – RPG Creature Search (HTML, CSS & JavaScript Project)

### 📌 Preview  
A sleek and interactive web app that allows users to search for RPG creatures by name or ID and instantly view their stats, types, and attributes.

---

### 📖 About the Project  
**Monster Vault** is a dynamic RPG creature lookup application that fetches real-time data from an external API. Users can search for a creature and instantly receive detailed information including stats, type classifications, height, weight, and more.

This project emphasizes working with asynchronous JavaScript by integrating API calls and handling responses efficiently. The app processes and maps incoming data into a clean, readable UI, giving it the feel of a mini in-game compendium or bestiary.

It also includes error handling for invalid searches and dynamically updates the page content without needing a refresh, creating a smooth and responsive user experience.

---

### 🚀 What I Learned  
- Working with **APIs and asynchronous JavaScript (fetch / async-await)**  
- Parsing and structuring **JSON data** from external sources  
- Using **objects and arrays** to map and organize complex data (stats, types)  
- Dynamically creating and updating **DOM elements**  
- Handling **user input and errors** gracefully  
- Managing **application state** when displaying fetched data  
- Building a more interactive, data-driven UI  

---

### 🛠️ Technologies Used  
- HTML5  
- CSS3  
- JavaScript  
- RPG Creature API (FreeCodeCamp)
